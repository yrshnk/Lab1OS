Программа состоит из трёх частей: Main, Creator и Reporter. Каждая выполняет отдельную задачу, обеспечивая создание, обработку и отображение данных о сотрудниках.

Утилита Creator создаёт бинарный файл с данными сотрудников. Она получает через командную строку имя файла и количество записей, после чего пользователь вводит данные каждого сотрудника: идентификационный номер, имя и количество отработанных часов. Все записи сохраняются в бинарном формате.

Утилита Reporter формирует текстовый отчёт на основе бинарного файла, созданного Creator. Она получает имя исходного файла, имя файла отчёта и оплату за час работы. В отчёте выводится заголовок с указанием исходного файла, шапка таблицы и список сотрудников с начисленной зарплатой, рассчитанной как произведение часов на ставку. Сотрудники сортируются по идентификационному номеру.

Программа Main управляет всей последовательностью работы. Она запрашивает имя бинарного файла и количество записей, запускает Creator и ожидает его завершения, затем выводит содержимое бинарного файла на консоль. После этого Main запрашивает имя файла отчёта и ставку, запускает Reporter и ждёт завершения, а затем выводит готовый отчёт на экран.

Для создания и управления процессами используются функции Windows API CreateProcess и WaitForSingleObject, что позволяет Main корректно синхронизировать работу с утилитами. Структура данных сотрудника хранится в отдельном заголовочном файле, а программа учитывает граничные случаи, такие как пустые файлы или длинные имена сотрудников.
